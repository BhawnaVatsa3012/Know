IKnOw codes

For the owner only. Make one-time sign-in links, or a code for a phone ID.

Works once, on the first phone that activates it, within 7 days.

To switch this phone off later, you'll need the link ID . Note it privately if you might.

Links and codes are worked out right here, in this browser. Nothing is sent anywhere from this page.

To switch a phone off later, add its link ID or phone ID to IKNOW_REVOKED_DEVICES in Vercel (separate several with commas), then redeploy.
